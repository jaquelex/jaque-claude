# Jaque para Claude

Contratación estatal colombiana dentro de Claude. Necesita una cuenta de Jaque con suscripción activa (https://jaque.pro).

## Instalar

En Claude Code o Cowork:

```
/plugin marketplace add jaquelex/jaque-claude
/plugin install jaque@jaque
```

Al usar por primera vez, Claude abre una pantalla de Jaque: entra con tu cuenta y pulsa **Permitir**.

## Qué trae

- **Conector** `https://jaque.pro/mcp`: verificar empresa, mayor contratista, contratos de un contratista, cronograma, buscar proceso, lectura guardada, tus datos y guía para observaciones. Solo lectura.
- **Habilidades**: `redactar-observaciones`, `revisar-proceso`, `revisar-pliego-y-diligenciar`, `verificar-contratista`, `mercado-entidad`.

## Topes diarios de consultas (por plan)

Contratista 30 · Oferente 100 · Completo 250 · Plus 500. Se renuevan a medianoche, hora de Colombia.
